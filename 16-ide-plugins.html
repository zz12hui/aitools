🖥 IDE 插件集成：VS Code 与 JetBrains

工具扩展篇 — 把 AI 助手嵌入你的编辑器

🎯 这篇讲什么

命令行好用，但直接在编辑器里和 AI 对话更爽。这篇教你给 VS Code 和 JetBrains 装上 AI 插件，让 Claude Code / OpenCode 出现在侧边栏。

🔌 Claude Code IDE 集成

Claude Code 原生支持 IDE 连接（VS Code / JetBrains）。

方式一：--ide 自动连接


# 启动 Claude Code 并自动连接 IDE
claude --ide

# 如果装了多个 IDE，会提示选择

方式二：VS Code 扩展

1. 打开 VS Code

2. 扩展市场搜索 "Claude Code"

3. 安装 Anthropic 官方扩展

4. 在 VS Code 里 Cmd/Ctrl+Shift+P → Claude Code: Open

功能

  • 📝 侧边栏对话
  • 🔍 选中代码直接提问
  • 📂 文件树感知上下文
  • ⚡ 一键应用 AI 生成的代码修改

🛠 Continue.dev：开源替代方案

[Continue](https://continue.dev) 是开源 AI 编程助手，支持 VS Code 和 JetBrains。

特点

ContinueClaude Code 扩展
开源✅ Apache 2.0❌
模型选择任意（OpenRouter/Local）Claude/DeepSeek
价格免费免费（需 API Key）
IDE 支持VS Code + JetBrainsVS Code + JetBrains

安装（VS Code）


# 方法一：扩展市场
# 搜索 "Continue" → 安装

# 方法二：命令行
code --install-extension Continue.continue

配置模型

~/.continue/config.json：


{
  "models": [
    {
      "title": "DeepSeek V4 Pro",
      "provider": "deepseek",
      "model": "deepseek-chat",
      "apiKey": "sk-你的密钥"
    },
    {
      "title": "Claude Sonnet",
      "provider": "anthropic",
      "model": "claude-sonnet-4-6",
      "apiKey": "sk-ant-你的密钥"
    }
  ],
  "tabAutocompleteModel": {
    "title": "DeepSeek V4 Flash",
    "provider": "deepseek",
    "model": "deepseek-chat"
  }
}

⚡ JetBrains 集成

Claude Code JetBrains 插件

1. JetBrains IDE → Settings → Plugins

2. 搜索 "Claude Code"

3. 安装 Anthropic 官方插件

4. 重启 IDE

5. 侧边栏出现 Claude Code 面板

Continue JetBrains 插件

1. Settings → Plugins → 搜索 "Continue"

2. 安装

3. 配置模型（同上 config.json）

🧩 OpenCode IDE 集成

OpenCode 也支持 IDE 连接：


# 启动 OpenCode 并连接 IDE
opencode --ide

# 或者在 TUI 中按 Ctrl+X E 打开编辑器模式

❓ 常见问题 (FAQ)

Q1: Claude Code 扩展和 Continue 能同时装吗？

能。它们互不冲突，可以按需切换使用。

Q2: Continue 收费吗？

完全免费开源。API 调用费用走你自己的 Key。

Q3: JetBrains 哪个插件最好？

Continue 功能最全且开源。Claude Code JetBrains 插件也不错。

Q4: IDE 里的 AI 会不会读到我的整个项目？

取决于配置。Continue 可以限制上下文范围。Claude Code 默认读工作区。

Q5: 代码自动补全怎么开？

Continue：tabAutocompleteModel 配置好模型即可。Claude Code 扩展目前不支持自动补全。

Q6: 需要单独装 Claude Code CLI 才能用 IDE 扩展吗？

Claude Code 官方扩展需要 CLI 已安装。Continue 不需要。

⚠ 避坑指南

坑正确做法
Continue 装完不能对话检查 config.json 的 API Key 是否正确
Claude Code 扩展连不上确认 CLI 已装：claude --version
JetBrains 插件冲突同类 AI 插件只装一个
IDE 卡顿限制上下文大小，不要加载整个项目
