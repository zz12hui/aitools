🦞 OpenClaw 介绍与迁移指南

工具扩展篇 — Hermes 的前身，如何迁移到新版本

🎯 这篇讲什么

OpenClaw 是 Hermes Agent 的前身，由 Nous Research 开发。Hermes Agent 是它的继任者。如果你之前用的是 OpenClaw，这篇教你无缝迁移到 Hermes。

📜 OpenClaw 是什么？

OpenClaw 和 Hermes Agent 的关系：


OpenClaw (旧) ──→ 停止维护 ──→ Hermes Agent (新)
   2024-2025                        2025-现在
  • 同一团队：都是 Nous Research
  • 功能继承：Hermes 保留了 OpenClaw 全部功能并大幅增强
  • 配置兼容：Hermes 提供一键迁移工具

🚀 一键迁移

Hermes 内置了迁移工具，能自动搬家：配置、记忆、技能、API Key。


# 1. 确保 Hermes 已安装
hermes --version

# 2. 运行迁移（自动检测 OpenClaw 目录）
hermes claw migrate

# 3. 迁移完成后清理旧文件
hermes claw cleanup

迁移了什么？

数据是否迁移
配置文件✅
API Key✅
对话记忆 (Memory)✅
技能文件 (Skills)✅
会话记录✅
插件⚠ 需手动重装

📂 OpenClaw 旧文件位置

如果迁移工具没自动检测到，手动指定路径：


# 默认位置
~/.openclaw/          # 配置和数据
~/.openclaw/.env      # API Key

# 迁移后这些目录可以删除
rm -rf ~/.openclaw/

🆕 迁移后需要做的事

1. 检查配置


hermes doctor
# 自动检查是否有遗漏的配置

2. 重新配置消息平台


hermes gateway setup
# OpenClaw 的平台配置会自动迁移，但建议手动检查一遍

3. 安装推荐的技能


hermes skills install web-search
hermes skills install self-improvement
hermes skills install obsidian

4. 测试一下


hermes chat -q "你好，能正常用吗？"

🤔 如果不想迁移会怎样？

OpenClaw 虽然停止维护，但已安装的还能继续用。不过：

  • 不会有新功能和安全更新
  • 新的 AI 模型可能不支持
  • 遇到问题没有社区帮助
  • 微信、Signal 等新平台不可用

🌍 从其他工具迁移到 Hermes

除了 OpenClaw，Hermes 还能从其他工具导入数据：


# 导入对话历史（JSONL 格式）
hermes sessions import ~/backups/

# 导入配置
hermes config migrate

❓ 常见问题 (FAQ)

Q1: 迁移会丢数据吗？

不会。迁移工具只读不删，完成后你手动 hermes claw cleanup 才会清理旧文件。

Q2: OpenClaw 的 Telegram Bot Token 还能用吗？

能。Token 不变，只是从 OpenClaw 换到 Hermes 使用。

Q3: 迁移后技能还能用吗？

大部分能。OpenClaw 的技能格式兼容 Hermes。部分可能需要小改。

Q4: 迁移失败怎么办？

先 hermes doctor 排查。也可以手动复制配置文件到 ~/.hermes/。

Q5: 还能回到 OpenClaw 吗？

迁移前备份 ~/.openclaw/ 目录即可随时恢复。

Q6: 我之前没听过 OpenClaw，需要关心吗？

不需要。直接从 2026-05-08 Hermes Agent 安装入门 开始即可。

⚠ 避坑指南

坑正确做法
迁移前没备份先 cp -r ~/.openclaw ~/openclaw-backup
迁移后两套配置冲突hermes claw cleanup 清理旧文件
网关同时启动了两个先停 OpenClaw 再启 Hermes
