🤖 系列总览：什么是 AI 编程助手？

第 0 篇 — 先搞清楚这俩东西到底是啥，再决定装不装

🧠 一句话解释

AI 编程助手 = 一个可以操作你电脑的 AI。

不像 ChatGPT 只能聊天，它能：

  • 📂 读写文件 — 直接帮你改代码
  • 💻 执行命令 — 帮你装软件、跑测试、部署项目
  • 🌐 上网搜索 — 自动查资料解决问题
  • 🔁 多轮迭代 — 写完代码自己测试，出错自己修

🔍 Claude Code 和 Hermes Agent 是什么关系？

维度Claude CodeHermes Agent
谁做的Anthropic（Claude 的公司）Nous Research（开源社区）
定位专用编程助手通用 AI 代理框架
模型Claude 系列 / DeepSeek任何模型（20+ 提供商）
平台终端 + IDE终端 + 微信/Telegram/Discord/...
开源否（但免费使用）是（MIT 协议）
风格专注写代码全能助手 + 多平台

简单比喻：

  • Claude Code = 雇了一个专门写代码的程序员
  • Hermes Agent = 雇了一个什么都能干的万能管家

🎬 它们能做什么？（真实场景）

Claude Code 擅长：


# "帮我把这个 2000 行的 Python 文件重构一下"
claude -p "Refactor auth.py to use async/await" --allowedTools "Read,Edit,Bash"

# "审查这个 PR 有没有安全漏洞"
git diff main...feature | claude -p "Security review this diff"

# "帮我给整个项目加类型注解"
claude -p "Add type hints to all public functions in src/"

Hermes Agent 擅长：

  • 在微信/Telegram 上和 AI 聊天
  • 定时检查服务器状态、自动发报告
  • 接入智能家居控制灯光
  • 管理 Obsidian 笔记库
  • 多个平台统一管理（一条消息控制所有 AI）

❓ 常见问题 (FAQ)

Q1: 我完全没写过代码，能看懂吗？

能。这个系列从「什么是终端」开始讲，不需要编程基础。但你要愿意打开终端敲命令。

Q2: 这两个和 ChatGPT 网页版有什么区别？

ChatGPT 只能聊天。Claude Code 能操作你的电脑——读写文件、执行命令、改代码。Hermes Agent 还能接入微信/Telegram，像私人管家一样随时待命。

Q3: 我的电脑配置够不够？

够。这俩本身不吃配置——它们只是「客户端」，真正的 AI 跑在云端。4GB 内存的笔记本就能用。

Q4: 装一个要多久？

Claude Code：5 分钟（前提是 Node.js 已装）。Hermes Agent：10-15 分钟（要装 Python 依赖）。

Q5: 能不能两个都装？

✅ 能，而且推荐！装了不冲突，还能联动（Hermes 指挥 Claude Code 写代码）。

Q6: 后续不想要了能删干净吗？

能。Claude Code：npm uninstall -g @anthropic-ai/claude-code && rm -rf ~/.claude。Hermes：hermes uninstall。

⚠ 新手最容易掉的坑

坑正确做法
以为能完全离线用不能。 每次对话都要联网调 API。想离线需要本地模型（Ollama），那是另一回事。
不看前置依赖就装先 node --version / python3 --version 确认版本够不够
装了不知道下一步干嘛装完先跑一次简单对话，别一上来就搞大项目
API Key 直接发群里Key = 银行卡密码，泄露了别人能盗刷你的额度
两个工具搞混命令Claude Code 用 claude，Hermes 用 hermes，互不影响
以为免费无限用软件免费，但 AI 调用按量收费。DeepSeek 一天就几毛钱，Anthropic 贵很多。
